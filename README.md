# Strong Mornings

No-equipment home strength and neck & back mobility: a 12-week morning plan.
Plain HTML/CSS/JS in a single `index.html`. No build step, no external requests, no data leaves the device.

Live site: https://iklass-m.github.io/strong-mornings/ (not indexed by search engines).

Install: open the link, then Chrome ⋮ → Add to Home screen (iPhone/iPad: Safari → Share → Add to Home Screen).
To publish changes: edit `index.html`, raise the number in `CACHE='strongmornings-v1'` in `sw.js`, then run "Publish Strong Mornings.bat".
